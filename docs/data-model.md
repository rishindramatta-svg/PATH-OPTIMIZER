JSON fields (including concept prerequisite lists and path snapshots) intentionally have no relational edges.

## Model notes

- `concepts` indexes: `ix_concepts_course_id`, `ix_concepts_slug`.
- `users` indexes: `ix_users_email`.
- `audit_logs` indexes: `ix_audit_logs_actor_user_id`.
- `course_enrollments` indexes: `ix_course_enrollments_course_id`, `ix_course_enrollments_instructor_id`, `ix_course_enrollments_user_course_role`, `ix_course_enrollments_user_id`.
- `mastery` indexes: `ix_mastery_concept_slug`, `ix_mastery_user_concept`, `ix_mastery_user_id`.
- `misconceptions` indexes: `ix_misconceptions_user_id`.
- `path_steps` indexes: `ix_path_steps_user_id`, `ix_path_steps_user_position`.
- `practice_sessions` indexes: `ix_practice_sessions_user_id`.
- `questions` indexes: `ix_questions_concept_slug`.
- `refresh_sessions` indexes: `ix_refresh_sessions_user_id`.
- `interactions` indexes: `ix_interactions_session_id`, `ix_interactions_user_created`, `ix_interactions_user_id`.
- Learner-owned rows reference `users.id`; the API obtains the owner from the authenticated cookie and does not accept a learner ID for these reads/writes.
- `concepts.prerequisites`, question options/tags, path snapshots/revisions, and audit details are JSON columns.
